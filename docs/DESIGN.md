# 长期设计规范

## 必须保留

1. 真实 Three.js 渲染。默认复用 v0.5.0 音乐盒 GLB、独立玻璃盖/磨砂边条/承托层、透射着色、环境反射、暖金灯带与原生镜头。不得用 CSS 旋转平面或伪玻璃替换。
2. 首次默认暖灰亮色：背景 `#eae5e1`，文字 `#302e2b`，信号 `#ac7a3d`；夜间深蓝 `#07111f`，文字 `#e5eaf0`，信号 `#d5ad71`。三维主题继续沿用原材质与照明过渡，不用全屏滤镜模拟。
3. MimaGlows 姓名与三条主链接贴近底部，备案独立位于右下角并保留安全边距。不要恢复已移除的 PERSONAL ARCHIVE / 序号 / RHINE 底部装饰栏。仅 Blog、Minecraft、Stronghold-Protocol 三个主要外链，大部分画面保留给空间、玻璃和动画。
4. 克制的刻度、细线、低对比工程标记。装饰文字不得演变成履历、技术栈、说明卡或大型控制台。
5. 布局与相机分别响应屏幕：移动端将签名和链接分行，选中卡片处于上部；不得通过非等比缩放 GLB 适配屏幕。

## 交互

真实链接始终是 HTML anchor，不允许为了选卡而拦截普通点击。链接可复制、可键盘访问；触摸区域至少 44px 高。主题、抽取、重播使用 button 和可读的 aria-label；刻度保留 aria-pressed。不要把“选中档案”误标为“当前网页”。

选择卡片用原 `select()` 和连续镜头；抽取用原 `setMode('detail')`，归位用 `setMode('archive')`；不得直接重置相机位置以制造切档。快速反向切换必须从当前状态继续。场景悬停有短延迟，避免指针经过阵列时频繁跳档。

开场是装饰性访客验证，不显示密码输入，不请求或储存身份信息。姓名与外链在开场期间照常可点击。首次三维淡入接管静态预览；重播再播放完整原生镜头。减少动态效果时取消开场、扫描、常态波动和自动视差，用户操作仍可立即改变状态。

## 完成改动的条件

涉及相机、材质、灯光或构图时，实际浏览器检查亮/暗、桌面/竖屏、抽取/归位及完整重播。重建实际 WebGL 预览图，防止首屏构图和实时场景脱节。至少检查无 JS、无 WebGL、模型失败和 reduced-motion。构建通过不能替代视觉验收；模拟手机不能写成真机验收。

首屏静态图使用原生场景的真实模型、玻璃和照明，但将非固定导航的档案图替换为本项目中性占位纹理再截图。不得把 OC/音乐/好友图永久烘焙到通用预览中，否则之后隐藏档案仍会在回退背景泄露其图片。动态场景准备后再加载当前允许公开的实际内容。

## 画面设置与档案阅读

画面入口只提供低、中、高三档，不向访客暴露 shader 参数。中、高档必须真实启用后处理 SMAA；画布原生 antialias 不能当作后处理管线已经抗锯齿。高档保留完整夜间星点及昼夜空间微粒、精细阴影/透射与高分辨率；仍尊重站点粒子总开关和减少动态效果。手动选择保存在本机，不被自动降级覆盖。

档案区参考原项目的面板留白、固定标题/分类和独立滚动：桌面扩大为目录与详情双栏，手机详情独立一栏并可返回。展开时仍保留底部三个外链与右下备案；不能用窄小浮层挤压长篇档案。
