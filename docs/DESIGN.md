# RHINE / CURATED ARCHIVE：长期设计规范

此规范记录用户选择的 A/B 组合：暖色科研展厅与深蓝档案终端。页面首先是一幅私人科研展览馆的空间画面，其次才是功能界面。冷静、克制、精密；避免控制台式面板、强发光边框、密集粒子或扫描线。

## 真实三维与双模式

- 两种模式复用同一 Three.js 场景、renderer、图集、上游 v0.5.0 GLB、玻璃透射材质、局部选中照明与连续相机；不得替换为 CSS 平面。
- FOCUS 是展品视角：一件清晰的大型档案为主体，保留少量相邻档案提供纵深，主体与界面之间留白。桌面为偏左的斜视，手机将主体放在上部。切换及抽取沿已有相机弹簧、模型升降和归位状态连续过渡，不得通过瞬移相机制造切档。
- ARCHIVE 是科研资料库：保留实体阵列的透视、重复、遮挡与局部光带；用较开阔的镜头呈现空间。不得改成二维网格或用背景图片代替可交互模型。
- 光照分别服务于暖灰 DAY 和深蓝 NIGHT：DAY 背景 `#ded7ce`、文字 `#302d29`、信号 `#9d6c33`；NIGHT 背景 `#101e2c`、文字 `#e6e8e6`、信号 `#d3ae7d`。玻璃边缘要可辨认，避免用增强 Bloom、过度景深或高亮粒子代替材质与层次。

## 页面与阅读

- 左下姓名、三个真实外链、右下备案均保留在静态 HTML，地址与文字由 `content/site.json` 管理。链接必须保持可复制、可键盘访问、触摸区域至少 44px，不拦截正常跳转。
- 顶部只保留模式、档案、抽取、画质和主题等必要入口；小字、间距和强调颜色遵循 `src/shell.css` 中统一规则，不能靠逐次追加冲突覆盖修补布局。
- 选中档案先显示轻量摘要和阅读入口；完整正文进入较宽、独立滚动的阅读状态，返回摘要与列表的路径清晰。移动端摘要位于下方，避免覆盖底部外链；正文面板在留出底部导航的同时保证可滚动。
- 不添加履历、技术栈、私人信息卡、大型控制台或多余装饰文字。首页不恢复已移除的底部装饰栏。

## 静态首屏、可访问与画质

- 姓名和三个链接不等 WebGL。FOCUS/ARCHIVE 各有桌面/手机、DAY/NIGHT 的真实三维 WebP；静态层按当前模式和主题选择，淡入后的相机与首屏构图保持一致。截图只允许固定导航的公开封面，其余档案一律用中性占位，避免隐藏内容被烘焙进回退背景。
- Three.js 继续动态 import；静态回退、上下文丢失、失败重试与省流量保留。保留键盘、触摸和鼠标；减少动态效果时取消开场、持续扫描、常态波动和视差，手动选择与主题仍工作。
- 画质只提供低/中/高；中高档真实使用 SMAA，高档保留完整粒子、精细阴影与透射。尊重站点粒子开关、设备预算和访客手动选择。

## 后续改动的验收

涉及镜头、材质、主题、画质或布局时，保留更改前截图，在相同视口/主题/模式/选中内容下重新截图；检查桌面与手机、亮暗、抽取/归位、长文与完整重播。重新生成全部八张中性真实场景预览，再运行 `npm run build` 和 `npm run check`；另检查无 JS、无 WebGL、模型失败和 reduced motion。记录浏览器、视口、缓存及网络条件；模拟设备不能写成真机或公网结果。保留 LICENSE、NOTICE 和上游素材权利说明。
